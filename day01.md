1. Чем отличается домен от рабочей группы?
Домен и рабочая группа — это два разных способа организации компьютеров в сети, 
которые кардинально отличаются по принципу управления, масштабу и уровню безопасности.
2.  Чем отличается Server Core от Desktop Experience?
Server Core и Desktop Experience (с графическим интерфейсом) — это два варианта установки Windows Server, которые кардинально отличаются по принципу работы, 
требованиям к ресурсам и подходу к управлению. 
Выбор между ними зависит от задач сервера, опыта администратора и приоритетов безопасности и производительности.
3. Для чего нужен статический IP на сервере?
Статический IP-адрес на сервере нужен для обеспечения стабильного и предсказуемого доступа к нему из сети Интернет. 
В отличие от динамического, он не меняется при переподключении к сети и закрепляется за устройством на длительный срок. 
Это критически важно для ряда задач, где требуется постоянный идентификатор. 
4. Какие 5 консолей вы изучили и для чего каждая из них?
1. eventvwr.msc — Просмотр событий.
2. services.msc — Службы.
3. diskmgmt.msc — Управление дисками.
4. compmgmt.msc — Управление компьютером.
5. gpedit.msc — Редактор локальной групповой политики.
